# Neural-Vision
Neural Vision is an AI-powered handwritten digit recognition application built using a Dense Neural Network and the MNIST dataset. It processes handwritten images by cropping, centering, resizing, and normalizing them for accurate prediction. Built with Python and Streamlit, it provides an interactive interface for real-time digit recognition.
